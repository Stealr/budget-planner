React, TypeScript, Vite, ESLint и Prettier входят в текущий каркас

## Данные и состояние

- **RTK Query** ведёт кеш сессии, операций, категорий, лимитов, дашборда и серверного предпросмотра выписки. После успешного добавления операции или подтверждения импорта инвалидируем теги `Transactions`, `Dashboard` и `Limits`.
- **Redux-слайсы** хранят общее состояние интерфейса и черновик импорта: шаг, ID предпросмотра, исключённые строки и правки категорий. Черновик сбрасывается при отмене или успешном завершении.
- **URL** хранит период и фильтры истории. Поля формы, пароль и выбранный объект `File` остаются в локальном состоянии.

## Проверки

- **Vitest** для схем валидации, редьюсеров и селекторов.
- **React Testing Library и MSW** для форм и поведения при загрузке, ошибках и успешных ответах API.
- **Playwright** для входа, добавления расхода и импорта выписки, включая проверку интерфейса на ширине 360 px.

## Текущий каркас

Маршруты входа, регистрации и разделов приложения открывают экраны каркаса. Авторизация и загрузка данных будут подключены после согласования API.

Общий модуль RTK Query находится в `src/store/api.ts`. По умолчанию он использует `/api` на том же домене. Для отдельного адреса API задайте `VITE_API_BASE_URL` при запуске Vite. Эндпоинты добавляются после согласования контракта через `api.injectEndpoints`.
