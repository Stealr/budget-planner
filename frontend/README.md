React, TypeScript, Vite, ESLint и Prettier входят в текущий каркас

## Данные и состояние

- **RTK Query** ведёт кеш сессии, операций, категорий, лимитов, дашборда и серверного предпросмотра выписки. После успешного добавления операции или подтверждения импорта инвалидируем теги `Transactions`, `Dashboard` и `Limits`.
- **Redux-слайсы** хранят общее состояние интерфейса и черновик импорта: шаг, ID предпросмотра, исключённые строки и правки категорий. Черновик сбрасывается при отмене или успешном завершении.
- **URL** хранит период и фильтры истории. Поля формы, пароль и выбранный объект `File` остаются в локальном состоянии.

## Проверки

- **Vitest** для схем валидации, редьюсеров и селекторов.
- **React Testing Library и MSW** для форм и поведения при загрузке, ошибках и успешных ответах API.
- **Playwright** для входа, добавления расхода и импорта выписки, включая проверку интерфейса на ширине 360 px.

## Текущий каркас

На экране «Операции» доступны история и добавление расхода через API. Маршруты входа, регистрации и остальных разделов пока открывают экраны каркаса.

Общий модуль RTK Query находится в `src/store/api.ts`. По умолчанию он использует `/api` на том же домене. Для отдельного адреса API задайте `VITE_API_BASE_URL` при запуске Vite. Эндпоинты операций и категорий подключены в `src/transactions/api.ts` через `api.injectEndpoints`.

## Запуск сценария добавления расхода

Для запуска всего приложения выполните из корня `docker compose up -d --build --wait` и откройте [«Операции»](http://localhost:8080/transactions). Для создания демонстрационной категории используйте тот же адрес API, что в примере ниже.

Для локальной разработки понадобятся Docker, JDK 21 и Node.js 24+. В отдельных терминалах запустите PostgreSQL, Spring Boot и Vite:

```powershell
# Из корня репозитория
docker compose -f backend/docker-compose.yml up -d --wait postgres
```

```powershell
Set-Location backend
.\gradlew.bat bootRun
```

```powershell
# Из корня репозитория
npm ci
npm run dev
```

Vite проксирует запросы `/api` на `http://127.0.0.1:8080`. При размещении фронтенда отдельно задайте `VITE_API_BASE_URL` с путём `/api` и настройте доступ к API.

В пустой базе один раз создайте демонстрационную категорию:

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8080/api/v1/categories -ContentType 'application/json; charset=utf-8' -Body '{"name":"Еда","type":"EXPENSE"}'
```

1. Откройте раздел «Операции» и нажмите «Добавить расход».
2. Введите `450,50`, выберите «Еда», оставьте сегодняшнюю дату и сохраните. Новые записи показываются первыми.
3. Перезагрузите страницу и проверьте, что запись осталась в списке.
4. Для проверки отказа создайте отдельную категорию расхода без операций, выберите её в форме и удалите через `DELETE /api/v1/categories/{id}` до сохранения. При сохранении API вернёт `404`, форма покажет ошибку категории и новая операция не появится.
