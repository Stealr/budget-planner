# СтудБюджет

СтудБюджет — учебный проект команды из трёх человек по курсу «Технологии программирования» НИТУ МИСИС. Мы разрабатываем веб-сервис, в котором студент сможет вручную учитывать доходы и расходы, планировать траты и следить за состоянием бюджета.

## Состояние проекта

В репозитории находятся проектная документация и минимальный каркас фронтенда на React и TypeScript. Бизнес-функции ещё не реализованы; язык и фреймворк бэкенда пока не выбраны. Описанные в документах функции и технические решения являются проектными требованиями и предложениями, а не реализованными возможностями.

## Структура

- `frontend/` — стартовый экран React, TypeScript и Vite.
- `backend/` — место для будущего серверного приложения.
- `docs/` — спецификация, бэклог, матрица трассируемости и журнал их изменений.
- `.github/` — шаблон pull request и автоматические проверки.

## Локальный запуск и проверки

Требуется Node.js 24 или новее. Клонируйте репозиторий по SSH, перейдите в его каталог и выполните:

```bash
npm ci
npm run dev
```

Vite выведет адрес локального стартового экрана. Для воспроизведения проверок pull request выполните:

```bash
npm run lint
npm run format:check
npm run build
```

Команда `npm run format` исправляет форматирование файлов, которые не исключены в `.prettierignore`. Три документа ПР1 пока исключены из автоформатирования, чтобы их первая версия оставалась точной копией исходных материалов.

## Командная работа

Новые задачи выполняются в коротких ветках и проходят проверку и ревью через pull request. Основные ветки: `main` для согласованного состояния, `develop` для интеграции изменений и `test` для проверки перед выпуском. Имена веток, формат коммитов и порядок ревью описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

В команде три человека: фронтенд-разработчик, бэкенд-разработчик и третий участник, чья роль пока уточняется.
