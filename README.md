# СтудБюджет

СтудБюджет — учебный проект команды из трёх человек по курсу «Технологии программирования» НИТУ МИСИС. Мы разрабатываем веб-сервис, в котором студент сможет вручную учитывать доходы и расходы, планировать траты и следить за состоянием бюджета.

## Состояние проекта

Фронтенд на React и TypeScript поддерживает регистрацию и вход, создание, редактирование и удаление доходов и расходов, историю с фильтрами, управление собственными категориями и их архивом. Бэкенд на Spring Boot также предоставляет API лимитов, дашборда и целей накопления; их интерфейс подключается следующими этапами. Данные хранятся в PostgreSQL, схему создаёт Liquibase.

## Структура

- `frontend/` — веб-интерфейс React, TypeScript и Vite.
- `backend/` — серверное приложение Spring Boot.
- `docs/` — спецификация, бэклог, матрица трассируемости и журнал их изменений.
- `.github/` — шаблон pull request и автоматические проверки.

## Запуск в Docker

Установите Docker с Compose v2 и из корня репозитория выполните:

```bash
docker compose up -d --build --wait
```

Откройте [интерфейс](http://localhost:8080), зарегистрируйтесь и войдите. Запросы к категориям и другим данным требуют Bearer-токен; в браузере его передаёт фронтенд. Стандартные категории уже создаются миграцией. Nginx обслуживает фронтенд и проксирует запросы `/api/` в Spring Boot. Бэкенд и PostgreSQL доступны внутри сети Compose.

```bash
docker compose ps
docker compose logs -f backend
docker compose down
```

После остановки данные остаются в томе PostgreSQL. Если порт 8080 занят, задайте `APP_PORT` в файле `.env` в корне, например `APP_PORT=8081`. Стек рассчитан на локальный запуск, опубликованный порт привязан к loopback.

## Локальный запуск и проверки

Требуется Node.js 24 или новее. Клонируйте репозиторий по SSH, перейдите в его каталог и выполните:

```bash
npm ci
npm run dev
```

Vite выведет адрес локального интерфейса. Для работы с данными запустите API по [инструкции фронтенда](frontend/README.md). Для воспроизведения проверок pull request выполните:

```bash
npm run lint
npm run format:check
npm run build
npm test
```

Команда `npm run format` исправляет форматирование файлов, которые не исключены в `.prettierignore`. Три документа ПР1 пока исключены из автоформатирования, чтобы их первая версия оставалась точной копией исходных материалов.

## Командная работа

Новые задачи выполняются в коротких ветках и проходят проверку и ревью через pull request. Основные ветки: `main` для согласованного состояния, `develop` для интеграции изменений и `test` для проверки перед выпуском. Имена веток, формат коммитов и порядок ревью описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

В команде три человека: фронтенд-разработчик, бэкенд-разработчик и третий участник, чья роль пока уточняется.
