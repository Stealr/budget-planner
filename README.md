# СтудБюджет

СтудБюджет — учебный проект команды из трёх человек по курсу «Технологии программирования» НИТУ МИСИС. Мы разрабатываем веб-сервис, в котором студент сможет вручную учитывать доходы и расходы, планировать траты и следить за состоянием бюджета.

## Состояние проекта

Сейчас в репозитории находится первая версия проектной документации из практической работы 1. Исходный код и командные настройки будут добавлены на следующем этапе. Описанные в документах функции и технические решения пока являются проектными требованиями и предложениями, а не реализованными возможностями.
