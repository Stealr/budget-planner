### 12.2. Расширенная матрица (требование → история → тест → компонент)
| ID | История | Приоритет | Тест (кратко) | Компонент | Статус |
|---|---|---|---|---|---|
| ФТ-1 | US-1 | Must | регистрация, дубль email, вход, доступ к чужим данным | Auth (API + страницы входа) | Proposed |
| ФТ-2 | US-2, US-3 | Must | добавление с суммой > 0; сумма 0 → ошибка | Transactions | Proposed |
| ФТ-3 | US-2 | Must | правка суммы пересчитывает баланс | Transactions | Proposed |
| ФТ-4 | US-2 | Must | новые пользователи получают стандартные категории; архивирование | Categories | Proposed |
| ФТ-5 | US-3 | Must | фильтр по периоду и категории | Transactions | Proposed |
| ФТ-6 | US-4 | Must | прогресс лимита = сумма расходов категории за месяц | Budgets | Proposed |
| ФТ-7 | US-6 | Must | сумма секторов = сумма расходов | Dashboard | Proposed |
| ФТ-8 | US-5 | Should | 79% → нет предупреждения, 80% → жёлтое, 101% → красное | Budgets | Proposed |
| ФТ-9 | US-7 | Should | пополнение цели не уменьшает расходы в отчёте | Goals | Proposed |

| ФТ-12 | US-4 | Could | лимиты в сумме = 100% дохода | Budgets | Proposed |

**Проверка покрытия:** у каждого БТ есть хотя бы одно ФТ; у каждого ФТ есть источник-БТ и история; «висящих» строк и столбцов нет.
